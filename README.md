# K53 Coach — Android MVP

A starter Android project for the K53 Coach learning app.

## Included
- Jetpack Compose UI
- Home dashboard
- Learn topics
- Daily 10-question test
- Instant explanations
- Basic scoring
- Mistake Bank placeholder
- Progress screen

## Next build
Add Room persistence, real mistake-bank storage, streaks, a larger reviewed question bank, road-sign images, onboarding, settings, offline content, analytics/crash reporting, Premium billing, and Play Store release configuration.

## Important
The sample questions are starter educational content and must be reviewed against current official South African learner-licence requirements before publication.
